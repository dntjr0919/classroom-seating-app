교실 자리 배치 프로그램 사용자 설명서

단 3번의 클릭으로 완성되는 공정하고 즐거운 교실 자리 배치! 긴장감 넘치는 슬롯머신 룰렛 추첨, 고정석/짝꿍 배치, 다양한 문서 인쇄 및 비공개 관리 기능까지 완벽하게 지원합니다.

🚀 1. 빠른 시작 가이드 (Quick Start)

프로그램 실행 파일(.exe)을 더블 클릭하면 별도의 복잡한 설치 과정 없이 즉시 실행됩니다.

1

명단 준비

상단 [⚙ 설정] ➔ [👥 학생 명단 관리]에서 학생 정보를 직접 입력하거나, 나이스(NEIS) 또는 엑셀 출석부 명단을 복사·붙여넣기하여 등록합니다.

2

책상 레이아웃 설정

상단 [⚙ 설정] ➔ [📐 책상 레이아웃 설정]에서 교실 행×열 크기 및 배치 형태(짝꿍형, 시험 대형, 모둠형 등)를 원클릭으로 선택합니다.

3

배치 실행

상단 툴바에서 원하는 배치 방식을 고른 뒤, 파란색 [🎲 배치 실행] 버튼(F5)을 누르면 배치가 즉시 시작됩니다.

💡 꿀팁: 첫 실행 시 샘플 명단 제공
프로그램을 처음 실행하면 20명의 예시 학생 명단과 5행×8열 짝꿍형 책상이 기본 세팅되어 있어 곧바로 테스트 배치를 해볼 수 있습니다!

🎲 2. 5가지 맞춤형 자리 배치 방식

학급 상황과 교육 활동 목적에 맞추어 드롭다운 메뉴에서 최적의 알고리즘을 선택할 수 있습니다.

1. 기본 무작위 배치

모든 학생을 완전 무작위로 추첨하여 활성 책상에 공정하게 배치합니다.

2. 남녀 이성 짝꿍 배치

2열 짝꿍 책상 구조를 자동 분석하여 남학생과 여학생이 1조를 이루도록 우선 매칭합니다.

3. 동성 짝꿍 배치

남-남 또는 여-여 학생이 짝꿍 좌석에 나란히 앉도록 배치합니다.

4. 번호순 자동 배치

출석번호 순서대로 정렬 배치합니다. 가로 우선(행 순서) 또는 세로 우선(열 순서)을 선택할 수 있습니다.

5. 앞뒤 구역 교차 배치

기존에 앞줄에 앉았던 학생은 뒷줄로, 뒷줄에 앉았던 학생은 앞줄로 공평하게 위치를 교차 이동시킵니다.

🎬 3. 긴장감 넘치는 슬롯머신 연출

단순한 결과 표시를 넘어, 교실 TV 화면에 띄워두고 학생들과 함께 두근거리는 마음으로 자리를 열람할 수 있습니다.

속도 조절 및 모드

  • ⚡ 빠르게: 자리당 0.3초 간격으로 신속하게 공개됩니다.
  • ⏱ 보통 (기본값): 자리당 0.5초 간격으로 리드미컬하게 공개됩니다.
  • 🐢 느리게: 자리당 1.0초 간격으로 극대화된 긴장감을 연출합니다.
  • 🖐 수동 오픈 모드: 전체 셔플 롤링 후 멈춰있는 상태에서 교사나 학생이 직접 좌석을 오픈합니다.
    • Space 또는 Enter 키를 누르면 다음 자리가 1개씩 순서대로 확정 공개됩니다.
    • 마우스로 특정 책상 카드를 직접 클릭하여 원하는 자리부터 깜짝 공개할 수도 있습니다.
💡 연출 스킵 및 연출 Off 옵션
애니메이션 재생 도중 ESC 키를 누르면 즉시 전체 자리가 완성 상태로 공개됩니다. 빠른 배치를 원하시면 상단 [🎬 슬롯머신 연출] 체크박스를 해제하세요.

📌 4. 고정석(Pin) 설정 및 대화형 수동 조작

📌 좌석 고정(Pin/Lock)

시력 보호, 다리 부상, 수업 집중 등의 사유로 자리를 유지해야 하는 학생은 책상 우측 상단의 [📌] 아이콘을 눌러 고정합니다. 다음 배치 시 고정석 학생은 그 자리에 남고 나머지 학생들만 재배치됩니다.

🔄 드래그 앤 드롭 & 클릭 맞바꾸기

배치 완료 후 미세 조정이 필요할 때, 책상 카드를 마우스로 드래그 앤 드롭하거나 두 책상을 순서대로 클릭하면 두 학생의 자리가 즉시 맞바뀝니다.

👤 우클릭 빠른 메뉴 (사전 배정)

책상 카드를 마우스 우클릭하면 특정 학생을 해당 자리에 직접 지정(Pre-set)하거나, 해당 좌석만 비우기(Clear)할 수 있습니다.

🧹 배정 초기화

[🧹 배정 초기화](Ctrl + Backspace) 클릭 시, 고정석(📌) 학생은 유지할지 여부를 묻는 스마트 팝업이 제공됩니다.

📤 5. 인쇄·게시용 문서 내보내기 & 엑셀 복원 저장

게시용 vs 교사용 180도 회전 시점 지원

상단 [📤 인쇄·게시용 내보내기 ▼] 버튼을 통해 학급 상황에 맞는 2가지 시점 문서를 출력할 수 있습니다.

  • 📋 게시용 (학생 시점): 교실 앞쪽 칠판/교탁이 문서 상단에 위치하여 교실 뒤쪽 게시판 부착 및 학생 열람에 최적화되어 있습니다.
  • 👩‍🏫 교사용 (180도 회전 시점): 교탁이 문서 하단에 위치하며, 교탁 앞에 선 선생님 시점에서 교실을 내려다보는 방향(좌우·앞뒤 반전)으로 인쇄됩니다. 출석 확인 및 수업 지도시 매우 편리합니다.

지원 파일 포맷

엑셀 파일(.xlsx), 인쇄용 웹 문서(.html), PDF 문서(.pdf), 한컴오피스 한글 문서(.hwp)를 지원합니다.

💡 엑셀 완전 복원 저장/불러오기 기능
[📁 파일] ➔ [💾 배치 엑셀 저장]을 실행하면, 현재 배치 상태뿐만 아니라 레이아웃 구조, 학생 명단, 고정석 여부까지 안전하게 보존됩니다. 언제든지 [📂 배치 엑셀 불러오기]로 이전 배치를 100% 동일하게 복원할 수 있습니다.

🔒 6. 교사용 비공개 히든 메뉴 (Hidden Admin)

학생들에게는 화면상으로 일체 노출되지 않으며, 오직 담임 교사만이 단축키와 보안 PIN 번호를 통해 진입하여 제어할 수 있는 특수 관리 기능입니다.

🔒 교사용 비공개 관리 기능 가이드 (클릭하여 열기/접기)
🔑 히든 메뉴 진입 및 보안 인증
프로그램 실행 화면에서 단축키 Ctrl + Shift + H를 누르면 보안 PIN 입력 대화상자가 나타납니다.
초기 마스터 PIN은 0000이며, 히든 창 내부의 [탭 1: 단축키 & 보안 설정]에서 원하는 4자리 번호 및 단축키로 변경할 수 있습니다.

🎯 기능 1: 다음 1회 강제 배치 프리셋

특정 학생을 원하는 좌석에 미리 내정해 두고, 다음 추첨 시 자연스럽게 그 자리에 배치되도록 합니다. 화면상에 고정 핀(📌) 표시가 전혀 붙지 않아 학생들은 조작 여부를 전혀 눈치챌 수 없습니다.

  • 📥 현재 자리 배치 불러오기: 메인 화면에서 마음에 드는 배치를 완성한 후 원클릭으로 프리셋 미니 그리드에 그대로 복사할 수 있습니다.
  • 미니 그리드 내 드래그 앤 드롭: 프리셋 창 안에서도 좌석 카드를 마우스로 드래그하여 학생 이동 및 자리 맞바꾸기가 가능합니다.
  • 단축키 무음 트리거 (Ctrl + Shift + F): 화면에 어떠한 팝업이나 표시줄 변경도 없이 '1회 강제 적용'을 켜거나 끌 수 있습니다. 1회 배치가 완료되면 플래그는 자동으로 Off로 리셋되어 단발성 배치가 보장됩니다.

🚫 기능 2: 근거리(1칸 이내) 배치 제외 설정

사이가 좋지 않거나 분리가 필요한 두 학생을 등록해 두면, 자리 배치 시 상하·좌우·대각선 8방향 1칸 이내(체비쇼프 거리 ≤ 1)에 인접하지 않도록 알고리즘이 자동으로 격리 배치합니다.

  • 무작위 추첨 후 두 학생이 1칸 이내로 붙으면 최대 1,000회 자동 재추첨을 시도합니다.
  • 만약 끝까지 해결되지 않을 경우, 제약 조건에 걸리지 않는 다른 학생과의 1:1 자동 맞바꾸기(Local Swap)를 통해 확실하게 분리합니다.

⌨ 7. 단축키 모음 요약표

모든 기본 단축키는 상단 메뉴 [⚙ 설정] ➔ [⌨ 단축키 설정](Ctrl + K)에서 선생님이 사용하기 편한 키로 자유롭게 변경할 수 있습니다.

기능 구분 기본 단축키 기능 설명
자리 배치 실행 F5 선택된 배치 방식과 옵션으로 자리 배치를 시작합니다.
학생 명단 관리 Ctrl + R 학생 명단 관리 대화상자를 엽니다.
책상 레이아웃 설정 Ctrl + L N×M 격자 크기 및 짝꿍/시험대형 레이아웃 디자이너를 엽니다.
배정 초기화 Ctrl + Backspace 좌석에 배정된 학생들을 비웁니다 (고정석 유지 옵션 지원).
인쇄/게시 문서 내보내기 Ctrl + E 게시용/교사용 문서(Excel, PDF, HTML, HWP) 내보내기 메뉴를 엽니다.
인쇄 / PDF 즉시 저장 Ctrl + P 게시용 PDF 문서를 즉시 내보냅니다.
배치 엑셀 저장 Ctrl + S 현재 배치 상태 및 명단을 복원 가능한 엑셀 파일로 저장합니다.
배치 엑셀 불러오기 Ctrl + O 이전에 저장한 엑셀 파일로부터 배치를 100% 동일하게 복원합니다.
단축키 설정 Ctrl + K 단축키 확인 및 변경 대화상자를 엽니다.
🔒 히든 관리자 메뉴 Ctrl + Shift + H 보안 PIN 인증 후 교사용 비공개 설정 대화상자를 엽니다.
🔒 강제 배치 무음 트리거 Ctrl + Shift + F 화면 노출 없이 다음 1회 강제 배치 적용 여부를 조용히 토글합니다.
슬롯머신 연출 스킵 ESC 진행 중인 룰렛 애니메이션을 즉시 건너뛰고 최종 결과를 표시합니다.
수동 1자리 오픈 Space / Enter 수동 오픈 모드에서 다음 좌석을 한 자리씩 확정 공개합니다.
